# db-agent 用户手册（新手版）

> 一个用自然语言查数据库的 AI Agent。你说人话，它帮你写 SQL、查数、分析、出图。
> 本手册面向第一次使用的人，5 分钟跑起来，10 分钟摸清全部功能。

---

## 1. 这是什么

**db-agent = 模型（LLM）+ Harness（工具/权限/记忆/编排/评测）。**

你输入一句中文，它会：

```
"销售部今年第一季度的订单总额是多少？"
  → Router 判断该查数据库
  → 先看表结构 → 写 SQL → 真实执行
  → 拿到结果 → 组织成中文回答
```

它能查：**SQLite（真实库）+ HBase / Hive（本地模拟器，API 对齐）**。

## 2. 快速开始（5 分钟）

```bash
# 1. 克隆
git clone https://github.com/TisseurdOr/db-agent.git
cd db-agent

# 2. 装环境（推荐 uv）
uv sync
source .venv/bin/activate

# 3. 配密钥
cp .env.example .env
# 编辑 .env，至少填 ANTHROPIC_API_KEY（没有它会启动即友好报错）

# 4. 跑起来
db-agent                    # 单 Agent 模式（等价于 python main.py）
db-agent --mode multi       # 多 Agent 编排模式（推荐）
```

> 没配 key 会看到：`❌ 缺少环境变量 ANTHROPIC_API_KEY。请先 cp .env.example .env...`
> ——不会崩，会告诉你该干嘛。

## 3. 能做什么（功能清单）

| 功能 | 说明 | 怎么触发 |
|---|---|---|
| 自然语言查 SQLite | 自动看表结构、写 SQL、执行、回答 | 直接问 |
| 多 Agent 编排 | Router 分派 sql/strategy/hbase/hive/analysis | `--mode multi` |
| 高频指标模板优先 | 常见指标不调 LLM，模板直接填 SQL | 自动 |
| Schema Linking | 只把相关表结构给模型，不整库塞 | 自动 |
| 权限控制 | 工具/表/行级权限，按角色 | `--user analyst` 等 |
| HITL 人工审批 | 敏感查询（薪资/成本）或 HBase 写操作先暂停问你 | 自动 |
| 记忆 | 短期对话压缩 + 长期向量记忆 | 自动 |
| 检索式 few-shot | 相似历史问题→已验证 SQL 注入 | 自动 |
| 自学习 | 成功 SQL 自动回流样例库 | `AUTO_LEARN_SQL=1` |
| 图表 | 结果可画 ECharts 图 | Web 端 / 问"画图" |
| 三层自愈 | 重试→SQL 重写→失败重规划 | 自动 |
| 熔断/幂等/告警 | LLM 挂了快速降级、副作用不重复、异常通知 | 自动 |

## 5. 配置说明（.env 每个变量）

### 必需
| 变量 | 说明 |
|---|---|
| `ANTHROPIC_API_KEY` | LLM 密钥（DeepSeek 兼容 Anthropic SDK）——**没有它启动即报错** |

### 强烈建议
| 变量 | 说明 |
|---|---|
| `ANTHROPIC_BASE_URL` | 默认 DeepSeek；可换 Kimi/OpenAI 兼容端点 |
| `EMBEDDING_API_KEY` | 向量记忆 / Schema Linking / few-shot 用（DashScope） |
| `KIMI_API_KEY` | Eval 的独立裁判模型（避免自评偏差） |

### 可选（都有默认值）
| 变量 | 默认 | 说明 |
|---|---|---|
| `AGENT_USER` | viewer | 角色：viewer/analyst/dba/manager/support |
| `LLM_MAX_RETRIES` | 3 | API 重试次数 |
| `CIRCUIT_BREAKER_THRESHOLD` | 5 | 连续失败多少次熔断 |
| `TOOL_IDEMPOTENCY_TTL` | 300 | 写工具幂等窗口（秒） |
| `ALERT_WEBHOOK_URL` | 空 | 告警推送（Slack/钉钉/飞书），空=只写日志 |
| `REDIS_URL` | 空 | 状态外置（会话+checkpoint），空=SQLite/内存 |
| `OPIK_ENABLED` | 0 | Opik 可观测上报 |

## 6. 试什么（示例提问）

```bash
db-agent --mode multi --user analyst
```

```text
> 上周哪个部门销售额最高？
> 对比一下 2025 和 2026 年的订单总额，哪年高？
> 销量最高的产品是哪个？
> 用 HBase scan orders 表前 10 行
> Hive 里有哪些表？
> 销售人员的提成比例是多少        # 走 strategy 查制度文档
> 你好，你能做什么                # 闲聊，不查库
> 帮我删掉 orders 表               # 会被权限/护栏拦截
> 查一下员工薪资最高的前 3 名      # 敏感列 → HITL 等你确认
> 退出
```

## 7. 挂了会怎样（可靠性：使用者视角）

| 情况 | 你会看到 |
|---|---|
| LLM API 偶发抖动 | 自动重试（指数退避），无感 |
| SQL 写错 | 自动把错误回喂重写，最多 2 次 |
| LLM 持续故障 | 熔断器打开 → `⚠️ 模型服务暂时不可用，请稍后重试`（不再白等白烧） |
| 断网/断线（Web） | SSE 心跳 + 前端自动重连 |
| 会话中断 | checkpoint 续跑（Redis 或 SQLite） |

## 10. 常见问题

**Q: 没有 Redis 能跑吗？** 能。`REDIS_URL` 留空自动用 SQLite + 内存，功能不变。

**Q: HBase/Hive 是真的吗？** 本地模拟器（API 对齐）。用于演示权限/HITL/编排，不连真实集群。

**Q: 换模型？** 改 `.env` 的 `ANTHROPIC_MODEL` / `ANTHROPIC_BASE_URL` 即可。

**Q: 数据在哪？** `db/demo.db`（业务数据）、`db/agent_state.db`（对话 checkpoint）、`harness/memory/chroma_db/`（向量记忆）。
