db-agent Harness 改造 3 天 × 16 小时作战计划  |  总计 48 小时

目标：给 db-agent 补全 s08–s11 四个 harness 机制，实现去中心化多 Agent 协作。
原则：不改现有代码，每次只加一个文件，每个 commit 可独立跑通。
产出：面试级项目 + HARENSS.md 讲稿 + benchmark 数据 + 模拟面试逐字稿。

目录

  1. 出发前：3 个原则
  2. Day 1（16h）：s08 后台任务 + s09 去中心化邮箱
  3. Day 2（16h）：s10 团队协议 + s11 自主认领 Agent + CLI
  4. Day 3（16h）：测试体系 + 文档 + 面试模拟
  5. 三天总览
  6. 最终 Check List

出发前：3 个原则

  1. 不改现有代码 — 每个新机制独立文件，通过 --mode team 入口接入。现有 single/multi 模式零影响。
  2. 每个 commit 可跑 — 不攒代码。写完一个机制 → 跑通 → commit。
  3. 代码即讲稿 — 每写完一步，在 HARNESS.md 里写 3 句"面试怎么讲这段话"。
