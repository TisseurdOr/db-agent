AI Agent 项目

db-agent — 企业级自然语言数据分析 Agent | 独立开发 | 2026.06 — 2026.07

Python LangGraph Anthropic SDK ChromaDB SQLite
  • 设计并实现了基于 LangGraph StateGraph 的多 Agent 编排引擎：Router 做意图分类 + 任务分派，SQL/Strategy/DataQuality 三个专业 Agent 各司其职，Analysis Agent 综合中间结果生成自然语言回答。支持单 Agent（ReAct Loop）和多 Agent 两种模式无缝切换。
  • 构建了 6 层安全防御链：guard_input（输入护栏）→ Router（意图分流）→ System Prompt（软约束）→ Entitlement 权限网关（工具授权 + 表白名单 + 行级 WHERE 改写 + 文档过滤）→ HITL 人工审批（LangGraph 原生 interrupt）→ guard_output（输出护栏）。权限数据存 DB，生产改一行 SQL 即生效。
  • 实现了基于 LangGraph interrupt() + Command(resume=...) 的 HITL 审批机制：Agent 检测到 salary/cost/budget 敏感列时，graph 自动暂停，CLI 展示待审批 SQL，用户确认后无缝恢复执行。
  • 搭建了 三层记忆系统：Working Memory（单轮 Tool 调用链）+ Short-term Memory（滑动窗口 + LLM 压缩摘要）+ Long-term Memory（ChromaDB 向量检索 + user_memory 结构化表）。结合 TokenBudget + HybridWindowManager 做主动压缩，避免上下文溢出。
  • 建立了 LLM-as-Judge Eval 体系：44 条回归测试覆盖正确性、完整性、安全性和路由准确性。用 Kimi kimi-k2.5 做独立评测模型（非被测模型，避免自评偏差），通过率 97.8%。
  • 设计了请求级 Trace 可观测性（TraceContext + Span），记录每个 Agent 节点的耗时、token 消耗和错误信息，落盘 JSONL 方便后续分析。
